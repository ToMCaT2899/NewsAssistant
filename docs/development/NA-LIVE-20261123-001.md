## 方法与边界

在 Docker Compose 一次性容器中调用生产 AgentRunner、NewsTools、发布服务、
outbox 和 QQSender；使用环境中的真实 deepseek-flash 模型和真实 QQ SMTP。
没有注入离线模型、RSS 或 SMTP 替身；使用临时 SQLite 数据库与工作区，
不启动调度器，不改变正常订阅和业务数据库，退出后删除隔离数据库。
只向配置的发件邮箱自发自收，不向第三方群发。

此结果证明真实服务层生成、来源持久化、邮件渲染和 SMTP 投递闭环；
不等同于已公开部署、真实浏览器操作触发生成、跨日定时调度或长期质量保证。
模型摘要依据已抓取原文并通过来源归属校验，不代表全部新闻主张已独立核实。
