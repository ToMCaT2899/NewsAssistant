## 需求映射

- C01 聊天入口：ChatView、会话列表、持久化消息、最近 8 轮上下文、只读资料工具。
- C02 动态工具状态：LangGraph 调用前/后审计，前端短轮询显示运行、成功、失败与耗时。
- C03 主动重生成：edition>0 新版本，与 edition=0 每日正式版分开，历史和来源保留。
- C04 显式推送：生成并推送模式与事务 outbox，关闭每日订阅仍能发送单次邮件。
- C05 权限与幂等：会话/简报归属、未验证邮箱拦截、同请求重放、每会话与订阅活动任务限制。
- C06 中文规范与复用：中文注释、现有 UI 色彩、无新增运行依赖，保持 Docker Compose 运行。

## 实现边界

普通聊天只读已有简报；需要重新收集或发送时，必须选择对应输入模式。
工具进度是可观察的实际执行状态，不展示或伪造模型隐藏推理。
轮询刷新不是逐 token 流式输出。旧“立即整理”按钮继续复用当天正式简报。
未实现任意工具授权、通用联网聊天、多 worker 横向扩展或无限上下文。
