# ADR 0005：用户自行配置模型

日期：2026-11-23。用户新增要求：前端模型设置、用户配置后才能使用，并完成项目收尾与推送。

## 决策与约束调整

新增个人模型设置 GET/PUT/DELETE `/api/v1/model-config` 与 POST `/api/v1/model-config/test`。
只接受当前登录用户身份，不能指定 user_id。状态接口、聊天、生成、到期调度使用个人配置，
不回退服务端 LLM_*；历史简报和订阅阅读不要求模型凭证。开启每日订阅要求先配置模型。
连接测试只调用一次 connection_probe，不执行工具、不发邮件；未返回有效工具协议视为失败。

用户本次明确要求网页输入模型凭证，因此替代原先“模型 Key 只走服务器环境变量”的实现规则。
通过 Fernet 加密将用户 Key 保存到 user_model_configs；主密钥 MODEL_ENCRYPTION_KEY、SMTP
授权码、JWT_SECRET 仍只由服务端环境提供。新增 cryptography 并锁定依赖。
API 不返回 Key 或密文；配置不进入模型上下文、工具审计或 run.snapshot_json。
API 地址和模型名是可回显的配置。更换地址必须显式提供新 Key，避免旧 Key 被转发到新服务。

## 生命周期与隔离

每个用户独立版本号，更新时校验旧版本；配置在有活动任务/聊天时不能改写或清除。
worker 按可信的订阅或会话 user_id 解密当前配置，构造本次调用的 Settings 副本，
不修改全局 Settings，不把一个账号的凭证借给另一个账号。注入的离线模型只存在于测试路径。
清除密钥保留递增版本行，避免删除再创建导致旧表单版本号被复用。
主密钥更换或丢失需要用户重新输入 Key，不能通过数据库备份恢复明文；部署迁移需保留主密钥。

## 网络边界

用户端点只支持公网 HTTPS 443；不支持本机/内网模型、查询参数、URL 内嵌凭证或自定义端口。
运行时解析 DNS，拒绝任何私网地址，并固定连接到已校验 IP，保留原 Host 与 TLS SNI。
HTTP 客户端不信任环境代理，不自动跟随重定向；整体模型请求有超时和响应大小限制。
保存配置只做结构校验；“已保存”不代表真实连接验证通过，测试结果另有时间标记。
