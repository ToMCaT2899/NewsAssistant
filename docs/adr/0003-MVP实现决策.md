# ADR 0003：MVP 实现与原设计落地

日期：2026-11-22～2026-11-23
状态：实现；真实模型、QQ SMTP 及公开部署仍待验证。

## Agent 与模型

使用 LangGraph StateGraph 的 budget_guard/agent/tools/validate 节点；
模型适配器接收实际 tools schema，返回 tool_calls，程序执行后回传 observation。
直接使用可配置的 chat-completions HTTP 协议，避免绑死某个付费供应商。
缺少凭证报 MODEL_NOT_CONFIGURED，默认生产路径没有假模型或假简报回退。
批次超出剩余工具预算时整批拒绝，不执行其中任意工具；记录拒绝审计，
计数保持实际已尝试执行次数，终止为 incomplete。

新闻采用已配置 RSS 源，search_news 仅在这些源内检索，非全网搜索。
来源 ID/URL 可配置，原文获取受公共 IP、DNS 绑定、跳转与体积限制。
run_articles 保存本次可引用来源，不能引用其他运行的文章或虚构链接。
模型输出被屏蔽词、条数、来源及证据级别校验；没有可靠新闻与获取失败分别处理。

## 数据与迁移

保留初始 001_initial.sql，追加 002_run_sources.sql。
用事务式编号 SQL runner 识别现有 schema_migrations，不额外引入一套不兼容 Alembic 历史。
ORM 仅映射，不通过 create_all 覆盖真实数据库。
调度的建任务与推进 next_run_at 是两个短事务：日幂等键兜底中间崩溃，
订阅 version 检查防止旧调度覆盖更新后的配置。
短暂重复扫描可复用已有 run，不会生成重复正式简报。

## 发布与邮件

关闭每日推送时允许手动生成网页简报；只有发布时仍启用且收件地址已验证才创建 outbox。
同日正式简报复用，不自动因之后开启订阅而补发历史简报。
SMTP 在图外执行；accepted/明确失败/unknown 分开。unknown 经核查确认后才重发。
超过自动次数后的手动重试保留历史序号，不把 attempt_count 清零。

## 工具链与 Compose

Vite 8.3.8 在 Windows 可构建，但 Linux npm ci 暴露可选 beta 依赖锁缺失，
固定 Vite 7.3.1 后保留严格锁文件校验。
增加显式 Prettier 配置，解决 Docker 前端上下文不包含仓库根 EditorConfig 时的格式差异。
应用使用官方 Python/Node 独立构建，前端运行层复用已有 Nginx 1.31.8 官方镜像的 digest。
默认 Compose 只启动业务服务，check/db-init 放 tools profile。
迁移服务仅在首次配置时 bootstrap 账号，不覆盖已有密码。
