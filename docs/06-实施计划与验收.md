## 阶段 1：CLI 最小 Agent（已实现，真实模型样本已验收）
接入已确认支持 tool calling 的模型和真实新闻搜索，锁定依赖。
实现五个基础工具和新闻工具，构建 agent/tools 循环、预算、结构化输出与日志。
验收：同一工具结果变化后，模型可以换关键词、补原文或结束；无固定搜索调用顺序。
检查搜索失败、非法参数、恶意正文、超预算、未知工具和无可靠新闻。
受限 bash 用允许命令实际执行验收；不能给模型开放完整主机权限。

## 阶段 2：数据库、API 与网页（已实现及离线/本地浏览器验证）
实现 ORM 与 DDL 一致性、认证、订阅、手动任务、简报历史和工具记录。
前端仅四个主要视图：登录、订阅、任务、简报详情。
验收：用户不能读取其他用户资源；幂等键重放不重复建任务；
同日手动请求复用正式简报；乐观锁冲突返回 409；未验证邮箱不能开启推送。

## 阶段 3：独立 worker 与 QQ 邮件（已实现，QQ 真实发送及收件已验收）
实现到期扫描、任务领取、过期恢复、outbox、TLS SMTP 和邮件模板。
使用测试邮箱完成实际发送验收，凭证从环境注入，测试默认不向真实用户群发。
验收：重复调度不重复发布；明确临时失败有限重试；
SMTP 接受后写库失败进入 unknown；重启不盲重发；关闭订阅取消待投递。
QQ 认证错误属于邮件失败，已经发布的简报仍可查看。

展示从订阅 → 工具调用 → 引用简报 → QQ SMTP 接受状态的闭环。

## 必测故障场景
1. 来源超时、只有摘录、发布时间未知、同一事件多转载。
2. 单个响应请求多个工具突破剩余预算；模型重试和格式修复不重置计数。
3. 文件越界、符号链接逃逸、shell 注入、网页内网跳转与提示词注入。
4. 双 worker 同时领取、发布事务失败、任务租约过期及迟到结果。
5. 同日重复触发、订阅中途修改、时区跨日与夏令时。
6. SMTP 接受、明确拒绝、认证失败、提交后超时与进程崩溃。
7. 邮件 HTML 转义、头部换行注入、日志和 Git 密钥泄露检查。
